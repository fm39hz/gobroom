# Source-backed encoded/signing provider vertical

Agent-selected bounded C6 proof under the standing implementation instruction.
Use the adjacent Qoder executor/COSY/encoding sources to exercise a difficult
wire adaptation through normal public connection/model/Physical/Combo controls,
actual HTTP serving and restart. Do not relabel the older three-field signing
mechanics fixture as an actual Qoder request.

The new typed payload follows the observed text-chat structure: generated
request/business IDs, stable session/record identifiers, forced upstream stream,
task/source/version fields, hoisted system, messages/tools, output parameters,
model_config and mirrored chat_context metadata. A selected native model config
is supplied as schema-bound request-codec options for this bounded fixture;
unknown outer option keys fail closed, while native model-config objects retain
vendor fields alongside their required typed key/output bounds. This proves independent configurability, not dynamic
catalog/login/media parity. It does not claim which source fields the real
server would permit omitting or that the provider accepts this code live.

Reuse the existing byte-bound COSY signer and prepared-byte replay contract.
Use stdlib Base64 custom alphabet/padding rather than maintaining a duplicate
alphabet mapper. Verify the final encoded bytes/hash/length/signature path at a
fake upstream; do not compare a signer only with its own output. Decode the
nested SSE envelope through the existing registered OpenAI semantic decoder,
not another text-only parser. Preserve tools/usage/finish/terminal behavior and
cancel/close the provider stream at DONE. Non-200/malformed/truncated envelopes
must not become success or automatic replay after upstream acceptance.

Use actual public setup metadata and credential connection actions, custom
models (which remain a supported workflow), schema-bound module options, exact
refs, provider leases and normal endpoint rendering. No provider-name branches
or new cache/data carrier hidden in auth/capability fields. No new dependency
unless evidence shows stdlib/existing codecs are insufficient. Only main Go,
format, test, install and commit; workers own disjoint files and stop for RED.

Alternatives rejected: copying a whole SDK, declaring the old toy payload real,
or inventing a kernel hook solely for this provider. Dynamic model-config
acquisition/persistence needs separate explicit provider/data-flow acceptance;
do not silently claim it from this configured-model vertical.
